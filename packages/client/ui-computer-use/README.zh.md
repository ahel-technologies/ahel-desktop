## 概述

电脑操作的浏览器界面：审批卡片、停止控制、活动日志和 Settings 中的屏蔽应用行。它通过 Host Remote 命名空间 `computerUseApproval` 读取动作门控（`@ahel/dsh-computer-use-action-gate`）。
