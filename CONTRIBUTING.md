# Contributing

English | [中文](CONTRIBUTING.zh.md)

- Issues are welcome: bug reports, questions and ideas.
- Pull requests are welcome. Keep each one focused on one change.
- Run `pnpm run build` and the tests for the packages you touched before you open one.
- Follow [AGENTS.md](AGENTS.md) for code and documentation conventions.
- No DCO or CLA sign-off is required.
